# ZenoPay Wallet

Last updated: March 2026

ZenoPay Wallet is a digital wallet application that allows users to manage their balance, send and receive money, make purchases, and access additional services in a secure and simple way.

---

## 📱 About the App

ZenoPay Wallet provides:

- Secure wallet management
- Send and receive money between users
- Deposit and withdrawal features
- Transaction history tracking
- Mobile shop (phones and products)
- Gift cards and top-up services
- Internal virtual card system

ZenoPay is **not a bank** and does not provide traditional banking services.

---

## 🔐 Privacy Policy

Your privacy is important to us.

We collect and process user data only as needed to operate the app, protect accounts, and provide services.

### Information We Collect
- Personal information (name, email, phone number)
- Account and profile data
- Wallet and transaction data
- KYC verification data (ID, selfie when required)
- Device and usage data

### How We Use Data
- To create and manage accounts
- To process wallet transactions
- To verify identity and protect accounts
- To improve app performance and security
- To provide support and updates

### Data Sharing
We do not sell user data. Data may only be shared with:
- Service providers (hosting, authentication, infrastructure)
- Payment or wallet-related services
- Legal authorities when required

## 🛡️ Security

We use standard security measures including:

- Data encryption

## 🗑️ Account Deletion

Users can delete their account inside the app:

**Settings → Security → Delete Account**

This will remove:
- Profile data
- Wallet data
- KYC data
- Transaction records (where applicable)
